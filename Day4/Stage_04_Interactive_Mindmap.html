📌 2. Core Concepts Cheat-Sheet

Step What it Does Why it's Required Golden Rule to Avoid Bugs
1. Leakage Guard Splits train & test first. Computing stats on full data leaks test info into training. fit() only on Train; transform() on Test.
2. Domain Features Constructs business ratios (e.g. charge / tenure). Absolute numbers miss velocity/rate signals. Use .replace(0, np.nan) then .fillna(0) to prevent zero-division.
3. Cardinality Reduction Groups categories with < 2% frequency into 'Other'. Prevents One-Hot Encoding from exploding into sparse columns. Freeze frequent categories from Train; apply to Test.
4. Categorical Encoding OHE for low-cardinality; Smoothed Target Encoding for high-cardinality. Algorithms only accept numerical matrices. Set drop='first' in OHE to defeat the Dummy Variable Trap.
5. Numerical Transform Yeo-Johnson power transform + RobustScaler (Median/IQR). Normalizes skewed distributions and puts scales on equal footing. Use RobustScaler over StandardScaler when outliers exist.
6. Feature Selection Funnel: Variance > 0.01 → Correlation < 0.85 → Top-K Mutual Info. Reduces overfitting, lowers training latency, improves explainability. Run cheap filters (VarianceThreshold) before expensive ones.
