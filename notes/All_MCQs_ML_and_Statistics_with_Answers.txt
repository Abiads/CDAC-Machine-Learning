Question 1 (Session Q1):
What is the primary characteristic that distinguishes Machine Learning from Traditional Programming?

Options:
  A) ML focuses on explicit rules, while Traditional Programming uses data-driven learning.
  B) ML systems improve over time with more data, unlike Traditional Programming.
  C) Traditional Programming is well-suited for complex tasks with large datasets.
  D) ML is rigid and requires human experts to anticipate all scenarios.

Correct Answer: B) ML systems improve over time with more data, unlike Traditional Programming.

Explanation:
  Machine learning systems are designed to improve their performance as they are exposed to more data, a fundamental difference from traditional programs that maintain a consistent performance level unless explicitly updated with new hard-coded rules.

Which of the following is NOT a primary goal of data preprocessing in machine learning?

Options:
  a) To ensure data is in a suitable format for model training.
  b) To reduce the computational cost of model deployment.
  c) To improve the accuracy and robustness of machine learning models.
  d) To handle inconsistencies and errors within the dataset.

Question 5 (Session Q2):
A dataset for a credit risk model contains numerous missing values in the 'Income' column. Which of the following imputation methods would typically introduce the least bias if the income distribution is skewed and contains outliers?

Options:
  a) Replacing missing values with the mean income.
  b) Removing all rows with missing income values.
  c) Replacing missing values with the median income.
  d) Using a constant value like 0 for all missing incomes.

Correct Answer: c) Replacing missing values with the median income.

Explanation:
  If the data distribution is skewed or contains outliers, the mean can be heavily influenced by these extreme values, leading to a biased imputation. The median is a more robust measure of central tendency in such cases, making it a better choice than the mean. Removing rows (b) can lead to significant data loss, and using a constant (d) can distort the distribution and introduce artificial patterns.

Question 6 (Session Q3):
You are preparing a dataset for a house price prediction model. One feature, 'Square Footage', shows a few extremely large values compared to the rest. Which action is generally recommended for handling these potential outliers?

Options:
  a) Always remove the rows containing these extreme values.
  b) Transform the 'Square Footage' feature using a logarithmic scale.
  c) Replace the extreme values with the mean of the 'Square Footage' column.
  d) Do nothing, as machine learning models can inherently handle outliers.

Correct Answer: b) Transform the 'Square Footage' feature using a logarithmic scale.

Explanation:
  Transforming skewed features like 'Square Footage' with a logarithmic scale can effectively reduce the impact of large outliers, making the distribution more symmetric and suitable for many machine learning models without discarding valuable data points (a) or introducing potential bias with mean replacement (c).

Question 7 (Session Q4):
You have a categorical feature 'Country' with 150 unique values in a customer dataset. Which encoding method would be most appropriate to prevent a drastic increase in the dataset's dimensionality while capturing the categorical information?

Options:
  a) One-Hot Encoding.
  b) Ordinal Encoding (assigning a random integer to each country).
  c) Label Encoding (assigning integers based on alphabetical order).
  d) Binary Encoding.

Correct Answer: d) Binary Encoding.

Explanation:
  One-Hot Encoding (a) would create 150 new columns, significantly increasing dimensionality and potentially leading to sparsity issues. Ordinal/Label encoding (b, c) would impose an artificial order on nominal data, which can negatively affect model performance. Binary encoding converts integers to binary codes and splits them into separate columns, significantly reducing the dimensionality compared to one-hot encoding while avoiding false ordinality.

Which of the following scenarios is an example of feature construction?

  b) Imputing missing values in a column using the KNN imputer.
  c) Deriving 'age_in_years' from a 'date_of_birth' column.
  d) Removing a feature that has a low correlation with the target variable.

Scaling (a) is feature transformation, imputation (b) is data cleaning, and removing features (d) is feature selection.

Question 9 (Session Q6):
What is the primary motivation for applying Principal Component Analysis (PCA) during data preprocessing?

Options:
  a) To transform non-linear relationships into linear ones.
  b) To handle missing values in a high-dimensional dataset.
  c) To reduce the number of features while retaining most of the data's variance.
  d) To encode categorical variables into numerical values.

Correct Answer: c) To reduce the number of features while retaining most of the data's variance.

Explanation:
  PCA is a linear dimensionality reduction technique. Its main goal is to project high-dimensional data onto a lower-dimensional space, capturing the maximum variance in the data with fewer orthogonal components. This helps combat the curse of dimensionality, reduces computational complexity, and can mitigate multicollinearity.

Question 10 (Session Q7):
In a dataset used to train a fraud detection model, 99% of transactions are legitimate and only 1% are fraudulent. What is this common data preprocessing challenge called, and which technique is commonly used to address it?

Options:
  a) High Dimensionality; addressed using PCA.
  b) Outlier Presence; addressed by removing extreme values.
  c) Imbalanced data; addressed using techniques like SMOTE (Synthetic Minority Over-sampling Technique).
  d) Missing Data; addressed using mean imputation.

Correct Answer: c) Imbalanced data; addressed using techniques like SMOTE (Synthetic Minority Over-sampling Technique).

Explanation:
  A significant difference in the number of instances of different classes (99% vs. 1%) is known as class imbalance. It can lead to models that perform poorly on the minority class. Techniques like SMOTE (Synthetic Minority Over-sampling Technique), random over-sampling, or under-sampling are commonly used during preprocessing to balance the class distribution.

Question 13 (Session Q3):
During the Model Training and Evaluation stage, why is "Hyperparameter Tuning" distinct from "Model Training"?

Options:
  A) Model training optimizes internal model parameters, while hyperparameter tuning optimizes external algorithm settings.
  B) Hyperparameter tuning occurs after the model has been deployed, while model training happens beforehand.
  C) Model training involves selecting evaluation metrics, while hyperparameter tuning evaluates model performance.
  D) Hyperparameter tuning is only applicable to unsupervised learning models, unlike model training.

Correct Answer: A) Model training optimizes internal model parameters, while hyperparameter tuning optimizes external algorithm settings.

Explanation:
  Model training is the process where the algorithm learns its internal parameters (e.g., weights in neural networks, split points in decision trees) directly from the training data. Hyperparameter tuning involves finding the best values for settings that control the learning process itself (e.g., learning rate, number of trees) and are set before training begins.

What is the primary purpose of implementing "continuous monitoring" after a machine learning model has been deployed?

Options:
  A) To continuously retrain the model on the original training data.
  B) To detect model drift and ensure the model remains accurate over time in a live environment.
  C) To generate explanations for all individual predictions made by the model.
  D) To automate the problem formulation process for future projects.

Correct Answer: B) To detect model drift and ensure the model remains accurate over time in a live environment.

Explanation:
  Continuous monitoring is crucial in the Model Deployment and Maintenance stage to track the model's performance in the real world. Over time, changes in input data distribution (data drift) or the relationship between inputs and outputs (concept drift) can degrade performance, necessitating monitoring to trigger retraining or updates.

Question 30 (Session Q6):
In the context of unsupervised learning, what is the primary advantage of DBSCAN over K-Means when the data might contain noise and clusters of irregular shapes?

Options:
  A) DBSCAN is faster than K-Means for large datasets.
  B) DBSCAN requires specifying the number of clusters (K) beforehand.
  C) DBSCAN can automatically discover the number of clusters and is robust to noise and irregular shapes.
  D) DBSCAN produces a hierarchical structure (dendrogram) that K-Means does not.

Correct Answer: C) DBSCAN can automatically discover the number of clusters and is robust to noise and irregular shapes.

Explanation:
  A key advantage of DBSCAN is its ability to find clusters of arbitrary shapes and identify outliers (noise) as points that don't belong to any cluster. Unlike K-Means, DBSCAN does not require the user to pre-specify the number of clusters (K), which can be a significant benefit when the true number of clusters is unknown. DBSCAN's speed depends on implementation and data; it doesn't generally produce dendrograms (that's Hierarchical Clustering).

Question 31 (Session Q7):
Which of the following statements accurately describes the role of "exploration vs. exploitation" in the context of choosing between supervised and unsupervised learning?

Options:
  A) It is primarily a dilemma in Reinforcement Learning, not directly applicable to supervised or unsupervised choices.
  B) Exploration refers to trying supervised models, while exploitation refers to using unsupervised models.
  C) It refers to the trade-off of collecting more labeled data (exploration) versus using existing unlabeled data (exploitation).

  A) It achieves perfect accuracy without needing any labeled data.

  B) To describe and summarize data
  C) To test hypotheses
  D) To establish causality

Correct Answer: B) To describe and summarize data

Explanation:
  Descriptive statistics aims to provide a summary of the main features of a dataset, making it easier to understand. Inferential statistics, hypothesis testing, and causal inference deal with drawing generalized conclusions about broader populations.

Question 3 (Session Q2):
Which measure of central tendency is most affected by outliers?

Options:
  A) Median
  B) Mode
  C) Mean
  D) Range

Correct Answer: C) Mean

Explanation:
  The arithmetic mean incorporates the exact magnitude of every single value in the dataset (sum divided by count). As a result, extreme outliers pull the mean heavily toward them. The median and mode are positional measures and remain unaffected by extreme outliers.
--------------------------------------------------------------------------------

Question 4 (Session Q3):
What does a standard deviation of 0 indicate?

Options:
  A) All values are different
  B) Data is widely spread
  C) All values are the same
  D) There are outliers in the data

Correct Answer: C) All values are the same

Explanation:
  Standard deviation quantifies the dispersion of values around the mean. If standard deviation = 0, there is zero variability around the mean, which guarantees that every single value in the dataset is identical.
--------------------------------------------------------------------------------

Question 5 (Session Q4):
If the mean and median are equal, the data is likely:

Options:
  A) Skewed right
  B) Symmetrical
  C) Skewed left
  D) Uniform

Correct Answer: B) Symmetrical

Explanation:
  In a symmetrical distribution (such as the standard normal distribution), the left and right halves are mirror images, causing the Mean, Median, and Mode to coincide at the central axis (Mean = Median = Mode).

Question 10 (Session Q1):
What does a right-skewed distribution indicate?

Options:
  A) The majority of values are low, with a few high values
  B) The majority of values are high, with a few low values
  C) The data is perfectly symmetrical
  D) The data has no variation

Correct Answer: A) The majority of values are low, with a few high values

Explanation:
  In a right-skewed (positively skewed) distribution, the bulk of observations are clustered at the lower end (left), while a long tail of infrequent, extreme high values stretches out to the right. In this case, Mean > Median > Mode.
--------------------------------------------------------------------------------

Question 11 (Session Q2):
Which measure is best for skewed data?

Options:
  A) Mean
  B) Median
  C) Mode
  D) Standard deviation

Correct Answer: B) Median

Explanation:
  The median represents the 50th percentile (exact middle value) and is robust to extreme values, unlike the mean and standard deviation which are disproportionately distorted by skewness and outliers.
--------------------------------------------------------------------------------

Question 12 (Session Q3):
What does a high positive kurtosis (leptokurtic distribution) indicate about a dataset?

Options:
  A) The data has lighter tails and fewer extreme outliers than a normal distribution.
  B) The distribution is skewed heavily to the right.
  C) The data has heavy tails and a higher risk of extreme outliers.
  D) The mean, median, and mode are all equal.

Correct Answer: C) The data has heavy tails and a higher risk of extreme outliers.

Explanation:
  Leptokurtic distributions possess positive excess kurtosis (> 0), characterized by a sharper central peak and fat, heavy tails. This indicates a significantly higher probability of extreme outlier events compared to a standard normal bell curve.
--------------------------------------------------------------------------------

Question 13 (Session Q4):
In a negatively skewed (left-skewed) distribution, which of the following relationships generally holds true?

Options:
  A) Mean > Median > Mode
  B) Mean < Median < Mode
  C) Mean = Median = Mode
  D) Median > Mean > Mode

Correct Answer: B) Mean < Median < Mode

Explanation:
  In a negatively skewed (left-skewed) distribution, the long tail extends toward the left due to extreme low values. These low values drag the mean down below the median, leading to the general ordering: Mean < Median < Mode.
--------------------------------------------------------------------------------

Question 14 (Session Q5):
How does Winsorizing handle extreme outliers in a dataset?

Options:
  A) It completely deletes the outlier observations from the dataset.
  B) It replaces extreme values with the nearest non-outlier percentile values (e.g., 5th or 95th percentile).
  C) It transforms the entire dataset using a logarithmic scale.
  D) It replaces all missing and extreme values with the dataset mean.

Correct Answer: B) It replaces extreme values with the nearest non-outlier percentile values (e.g., 5th or 95th percentile).

Explanation:
  Winsorization limits the influence of outliers by capping values beyond specified percentiles (e.g., values below the 5th percentile are set to the 5th percentile value, and values above the 95th percentile are set to the 95th percentile value) instead of trimming/removing records.
--------------------------------------------------------------------------------

Question 15 (Session Q6):
How is the Interquartile Range (IQR) calculated, and why is it preferred over standard deviation for skewed data?

Options:
  A) IQR = Q3 - Q1; it is robust to extreme outliers.
  B) IQR = Q4 - Q1; it covers 100% of the dataset.
  C) IQR = Q3 + Q1; it measures the total variance of the sample.
  D) IQR = Mean - Median; it measures the symmetry of the data.

Correct Answer: A) IQR = Q3 - Q1; it is robust to extreme outliers.

Explanation:
  The Interquartile Range is computed as the difference between the 75th percentile (Q3) and the 25th percentile (Q1). By focusing strictly on the middle 50% of the dataset, it completely filters out extreme tail values, providing a robust measure of statistical dispersion for skewed distributions.

Question 16 (Session Q1):
If events A and B are independent, P(A ∩ B) is:

Options:
  A) P(A) + P(B)
  B) P(A) - P(B)
  C) P(A) * P(B)
  D) None of the above

Correct Answer: C) P(A) * P(B)

Explanation:
  By the fundamental multiplication rule of probability, when two events A and B are independent (the occurrence of one does not affect the probability of the other), their joint probability is the product of their individual probabilities: P(A ∩ B) = P(A) * P(B).

Question 26 (Session Q1):
p = 0.03 -> ? (assuming standard alpha = 0.05)

Options:
  A) Accept H0
  B) Reject H0

Correct Answer: B) Reject H0

Explanation:
  Because the p-value (0.03) is less than the significance threshold alpha (0.05), the observed test statistic is unlikely to have occurred under H0 alone, leading us to reject the null hypothesis.
--------------------------------------------------------------------------------

Question 27 (Session Q2):
CI = (48, 52), mu0 = 53 -> ?

Options:
  A) Reject H0
  B) Accept H0

Correct Answer: A) Reject H0 (when hypothesized mean is outside the CI, reject the null hypothesis)

Explanation:
  The hypothesized value mu0 = 53 falls completely outside the 95% Confidence Interval (48, 52). A value outside the confidence interval is statistically incompatible with the observed sample at that confidence level, leading to the rejection of H0.
--------------------------------------------------------------------------------

Question 28 (Session Q3):
p = 0.07, alpha = 0.05 -> ?

Options:
  A) Reject H0
  B) Fail to reject H0

Correct Answer: B) Fail to reject H0

Explanation:
  Because the p-value (0.07) is greater than alpha (0.05), the difference could reasonably be attributed to random sampling variability. Therefore, there is insufficient evidence against H0, and we fail to reject the null hypothesis.
