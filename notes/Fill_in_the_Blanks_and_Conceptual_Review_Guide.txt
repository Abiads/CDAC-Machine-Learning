QUESTION 1.1:
"A DataFrame is a ______ data structure used for data manipulation in Python."

  ANSWER: two-dimensional (2D)

  IN-DEPTH EXPLANATION:
  - In Pandas, the two foundational data structures are the Series and the DataFrame.
  - A Series is a 1-dimensional labeled array capable of holding data of any type.
  - A DataFrame is a 2-dimensional labeled data structure with columns of potentially
    different types. It is structured like a spreadsheet or SQL table with both
    row labels (index) and column labels.
  - Mathematical representation: A DataFrame can be modeled as a matrix M of size
    m x n, where m is the number of rows (observations) and n is the number of 
    columns (variables/features).
  - Python implementation:
      import pandas as pd
      df = pd.DataFrame({'Age': [25, 30], 'Salary': [50000, 75000]})
      print(df.ndim)  # Outputs: 2

--------------------------------------------------------------------------------

QUESTION 1.2:
"In a Data Table, the horizontal sections are called ______, and the vertical 
sections are called ______."

  ANSWER: rows, columns

  IN-DEPTH EXPLANATION:
  - Rows (Horizontal): Represent individual records, observations, samples, or instances.
    In machine learning, each row corresponds to a single data point vector x_i.
  - Columns (Vertical): Represent attributes, features, variables, or dimensions measured
    for each observation.
  - Terminology Equivalence:
    * Relational Databases: Row = Record / Tuple; Column = Attribute / Field.
    * Machine Learning: Row = Instance / Sample; Column = Feature / Predictor.
    * Statistics: Row = Observation / Case; Column = Variable / Measurement.

--------------------------------------------------------------------------------

QUESTION 1.3:
"A dictionary in Python stores data as ______ pairs."

  ANSWER: key-value

  IN-DEPTH EXPLANATION:
  - A Python dictionary (`dict`) is an unordered, mutable collection of associative items.
  - Each item consists of a unique, immutable 'key' (such as a string, integer, or tuple)
    mapped to a 'value' (which can be any arbitrary Python object).
  - Time Complexity: Key lookups, insertions, and deletions have an average time 
    complexity of O(1) due to underlying hash table implementation.
  - Relation to Pandas: A Pandas DataFrame is internally implemented as a dictionary-like 
    container for Series objects, where keys correspond to column names.

--------------------------------------------------------------------------------

QUESTION 1.4:
"A tuple is similar to a list, but it is ______, meaning its values cannot be changed."

  ANSWER: immutable

  IN-DEPTH EXPLANATION:
  - Mutability distinguishes lists from tuples in Python:
    * Lists (`[...]`): Mutable. Elements can be added, removed, or modified in-place.
    * Tuples (`(...)`): Immutable. Once created, their size and element bindings 
      cannot be altered.
  - Why Immutability Matters:
    1. Integrity: Guarantees write-protection for sensitive, constant configuration data.
    2. Hashability: Because tuples are immutable, they are hashable and can serve as 
       dictionary keys or set elements, whereas lists cannot.
    3. Performance: Tuples have smaller memory overhead and slightly faster allocation 
       times compared to dynamic lists.

QUESTION 1.5:
"The process of summarizing and organizing data to extract useful insights is called ______."

  ANSWER: data analysis (or Exploratory Data Analysis - EDA)

  IN-DEPTH EXPLANATION:
  - Data analysis is the systematic process of applying statistical and logical techniques 
    to describe, condense, illustrate, and evaluate data.
  - Core stages of modern Data Analysis:
    1. Data Collection: Sourcing raw data from databases, APIs, or sensor streams.
    2. Data Cleaning: Handling nulls, correcting formatting anomalies, trimming whitespace.
    3. Exploratory Data Analysis (EDA): Generating summary statistics (mean, median, IQR), 
       frequency tables, and visualizations to reveal latent patterns.
    4. Inferential Modeling: Drawing statistical hypotheses or predictive conclusions.

QUESTION 1.7:
"A structured collection of data that is stored electronically and can be queried is 
known as a ______."

  ANSWER: database

  IN-DEPTH EXPLANATION:
  - A database is an organized collection of structured data, typically stored electronically 
    in a computer system and managed by a Database Management System (DBMS).
  - Main categories:
    1. Relational Databases (RDBMS): PostgreSQL, MySQL, SQLite, Oracle (tabular, strict schemas, SQL).
    2. NoSQL Databases: MongoDB (Document), Redis (Key-Value), Cassandra (Columnar), Neo4j (Graph).

QUESTION 1.8:
"The function used to remove missing values from a DataFrame is ______."

  ANSWER: dropna()

  IN-DEPTH EXPLANATION:
  - In Pandas, missing or null values are represented by `NaN` (Not a Number) or `None`.
  - The `dropna()` method filters out rows or columns containing missing values.
  - Key Parameters:
    * `axis=0` (default): Drops rows containing NaN.
    * `axis=1`: Drops columns containing NaN.
    * `how='any'` (default): Drops the row/column if at least one NaN is present.
    * `how='all'`: Drops only if all entries in that row/column are NaN.
    * `subset=['col1', 'col2']`: Restricts null-checking to designated columns.
  - Best Practice Consideration: Dropping data can lead to substantial information loss. 
    If nulls exceed 5-10% of records, imputation (`df.fillna(df.median())`) is usually 
    preferred over blanket row deletion.

QUESTION 2.1:
"______ features represent categories or groups."

  ANSWER: Categorical (or Qualitative)

  IN-DEPTH EXPLANATION:
  - Categorical variables represent qualitative characteristics that fall into distinct bins.
  - Subtypes:
    1. Nominal Categorical: Categories without inherent mathematical ordering.
       Examples: Gender (Male, Female, Other), City (Mumbai, Delhi, Bangalore), Blood Type (A, B, AB, O).
    2. Ordinal Categorical: Categories with an intrinsic, meaningful hierarchy or order.
       Examples: Education Level (High School < Bachelor's < Master's < PhD), 
       Customer Satisfaction (Dissatisfied < Neutral < Satisfied), Severity (Low < Medium < High).
  - Preprocessing Requirement: Machine learning models cannot process raw strings; categorical 
    variables must be encoded into numerical values via One-Hot Encoding or Ordinal Encoding.

--------------------------------------------------------------------------------

QUESTION 2.2:
"A ______ feature can take any value within a range."

  ANSWER: Continuous

  IN-DEPTH EXPLANATION:
  - Continuous features are quantitative variables obtained through measurement.
  - Distinctive property: Between any two continuous values, there exist an infinite 
    number of intermediate values along the real number line.
  - Examples:
    * Height (e.g., 175.42 cm)
    * Temperature (e.g., 36.65 °C)
    * Stock Price (e.g., 2450.75 INR)
    * Time to complete a marathon (e.g., 2 hours, 14 minutes, 33.12 seconds)
  - Visual Representation: Continuous data is commonly visualized using histograms, 
    KDE (Kernel Density Estimation) plots, and box plots.

--------------------------------------------------------------------------------

QUESTION 2.3:
"The count of items purchased is an example of a ______ feature."

  ANSWER: Discrete

  IN-DEPTH EXPLANATION:
  - Discrete features are quantitative variables obtained through counting.
  - Distinctive property: They take distinct, separate numerical values—typically 
    non-negative integers {0, 1, 2, 3, ...}.
  - Examples:
    * Number of children in a household (0, 1, 2, ... cannot have 2.3 children)
    * Number of items purchased in a shopping cart
    * Count of website visits per day
    * Number of customer service calls made
  - Probability Modeling: Discrete counts are typically modeled using Poisson, 
    Binomial, or Negative Binomial distributions.

QUESTION 3.1:
"______ measures the asymmetry of a data distribution."

  ANSWER: Skewness

  IN-DEPTH EXPLANATION:
  - Skewness is the 3rd standardized moment of a probability distribution.
  - Formula: Skewness = E[((X - mu) / sigma)^3]
  - Classification:
    * Symmetrical (Skewness ≈ 0): Normal bell curve where Mean = Median = Mode.
    * Positive / Right-Skewed (Skewness > 0): The right tail is longer. The majority 
      of data points cluster at lower values, while a few extreme high values pull 
      the mean to the right. Ordering: Mean > Median > Mode.
      Real-world example: Household income, house prices, insurance claim sizes.
    * Negative / Left-Skewed (Skewness < 0): The left tail is longer. Extreme low 
      values pull the mean to the left. Ordering: Mean < Median < Mode.
      Real-world example: Human lifespan in developed countries, retirement age.

--------------------------------------------------------------------------------

QUESTION 3.2:
"The ______ rule states that 95% of data falls within 2 standard deviations 
of the mean in a normal distribution."

  ANSWER: 68-95-99.7 Rule (or Empirical Rule)

  IN-DEPTH EXPLANATION:
  - In any symmetrical, bell-shaped Gaussian (Normal) distribution N(mu, sigma^2):
    * Approximately 68.27% of observations fall within mu ± 1 sigma.
    * Approximately 95.45% of observations fall within mu ± 2 sigma.
    * Approximately 99.73% of observations fall within mu ± 3 sigma.
  - Statistical Significance: Observations lying beyond 3 standard deviations 
    (|z| > 3) represent only ~0.27% of the distribution and are universally 
    flagged as statistical outliers.

--------------------------------------------------------------------------------

QUESTION 3.3:
"If the tails of a distribution are heavier than normal, it is called ______ kurtosis."

  ANSWER: Leptokurtic (or Positive Kurtosis)

  IN-DEPTH EXPLANATION:
  - Kurtosis measures the "tailedness" and peak sharpness of a distribution 
    (the 4th standardized moment).
  - Normal distribution reference: Excess Kurtosis = Kurtosis - 3 = 0 (Mesokurtic).
  - Three Kurtosis Types:
    1. Leptokurtic (Excess Kurtosis > 0): Sharp, high peak and fat, heavy tails.
       Critical implication: Indicates high "tail risk"—a significantly greater probability 
       of extreme, rare outlier events than predicted by a normal distribution. 
       Common in financial asset returns and algorithmic trading.
    2. Mesokurtic (Excess Kurtosis = 0): Standard normal distribution.
    3. Platykurtic (Excess Kurtosis < 0): Flat, broad peak with thin, light tails. 
       Extreme outliers are very rare. Example: Uniform distribution.

PROBLEM 4.1:
"What is the probability of rolling a number greater than 4 on a fair six-sided die?"

  ANSWER: 1/3 (or ~33.33% / 0.333)

  SOLUTION BREAKDOWN:
  - Sample Space (S): The set of all possible outcomes for a fair 6-sided die:
    S = {1, 2, 3, 4, 5, 6} -> Total outcomes n(S) = 6.
  - Event (E): Rolling a number strictly greater than 4:
    E = {5, 6} -> Favorable outcomes n(E) = 2.
  - Classical Probability Formula:
    P(E) = n(E) / n(S) = 2 / 6 = 1 / 3 ≈ 0.3333 (33.33%).

  EXTENDED PROBABILITY AXIOMS:
  1. Non-negativity: 0 <= P(E) <= 1 for any event E.
  2. Total Certainty: P(S) = 1.
  3. Complement Rule: P(E') = 1 - P(E) = 1 - 1/3 = 2/3 (Rolling <= 4).
  4. Independent Events Multiplication Rule: P(A ∩ B) = P(A) * P(B).
     Example: Probability of rolling two 6s consecutively = (1/6) * (1/6) = 1/36.

CONCEPT 5.1: THE BINOMIAL DISTRIBUTION (POLLUTION INSPECTION NUMERICAL)
Scenario from Slide 15:
"In an inspection of cement companies, 60% of all industries had emissions that 
do not meet the pollution requirement. For a random sample of 15 companies, 
compute:
1. Probability that all 15 fail the inspection.
2. Probability that exactly 8 fail the inspection."

  FORMULA:
  P(X = k) = C(n, k) * (p^k) * (q^(n - k))
  where:
  - n = 15 (sample size)
  - p = 0.60 (probability of failure / non-compliance)
  - q = 1 - p = 0.40 (probability of compliance)
  - C(n, k) = n! / (k! * (n - k)!)

  COMPUTATION 1: All 15 Fail (k = 15)
  - P(X = 15) = C(15, 15) * (0.60^15) * (0.40^0)
  - C(15, 15) = 1, 0.40^0 = 1
  - P(X = 15) = 0.60^15 ≈ 0.000470 (0.047%)

  COMPUTATION 2: Exactly 8 Fail (k = 8)
  - C(15, 8) = 15! / (8! * 7!) = 6,435
  - 0.60^8 ≈ 0.016796
  - 0.40^7 ≈ 0.0016384
  - P(X = 8) = 6435 * 0.016796 * 0.0016384 ≈ 0.17708 (17.71%)

CONCEPT 5.2: THE POISON DISTRIBUTION UNIQUE PROPERTY
"Which distribution has Mean = Variance?"

  ANSWER: Poisson Distribution

  IN-DEPTH EXPLANATION:
  - A Poisson process models the count of rare events occurring within a fixed interval 
    of time, distance, or space.
  - Probability Mass Function: P(X = k) = (lambda^k * e^(-lambda)) / k!
  - Key Parameter: lambda represents both the arrival rate and expected occurrences.
  - Derivation of Moments:
    * E[X] = lambda
    * Var(X) = lambda
  - Diagnostic Tip: In exploratory data analysis, if sample mean ≈ sample variance, 
    the count data is a strong candidate for Poisson modeling. If variance >> mean, 
    the data is overdispersed and requires a Negative Binomial model.

DECISION RULE TABLE FOR HYPOTHESIS TESTING:

  Parameter Tested       Sample Size (n)   Pop. SD Known?    Appropriate Test
  --------------------   ---------------   ---------------   ----------------
  Single Mean            n >= 30           Yes or No         Z-test (CLT holds)
  Single Mean            n < 30            Yes               Z-test
  Single Mean            n < 30            No                Student's T-test
  Two Independent Means  n1, n2 < 30       No                Two-sample T-test
  Proportions / A/B      n1, n2 large      Binomial          Two-proportion Z-test
  Categorical Freqs      Any               Contingency       Chi-Square Test

ERROR CLASSIFICATION MATRIX:

                             Truth: H0 is True        Truth: H0 is False
  ------------------------   ---------------------    ---------------------
  Decision: Reject H0        Type I Error (alpha)     Correct Decision (Power = 1 - beta)
  Decision: Fail to Reject   Correct (1 - alpha)      Type II Error (beta)

P-VALUE INTERPRETATION BENCHMARK (alpha = 0.05):
- p-value < 0.05: Reject H0. The observed evidence is statistically significant.
- p-value >= 0.05: Fail to reject H0. Insufficient evidence against the null baseline.
- Confidence Interval Rule: If the hypothesized parameter value mu0 lies OUTSIDE the 
  95% Confidence Interval (L, U), reject H0 at alpha = 0.05.

1. SUPERVISED LEARNING vs UNSUPERVISED LEARNING vs REINFORCEMENT LEARNING
------------------------------------------------------------------------
Dimension         Supervised               Unsupervised              Reinforcement
Data Type         Labeled (X, y)           Unlabeled (X)             Environment States (S)

Algorithms        Linear Reg, Naive Bayes  K-Means, PCA, DBSCAN      Q-Learning, Policy Gradient
Feedback          Direct ground truth      No external ground truth  Delayed rewards/penalties

2. FEATURE SCALING: NORMALIZATION vs STANDARDIZATION
---------------------------------------------------
- Min-Max Normalization: Rescales values to range [0, 1].
  Formula: X_scaled = (X - X_min) / (X_max - X_min)
  Best used when: Algorithms require bounded boundaries (e.g., neural nets, image pixels).
  Limitation: Highly sensitive to outliers.

- Z-Score Standardization: Rescales values to Mean = 0, Standard Deviation = 1.
  Formula: X_standardized = (X - mu) / sigma
  Best used when: Features have different units, algorithms assume normality (PCA, SVM, Linear Regression).
  Advantage: Does not bound values, robust to outliers.
