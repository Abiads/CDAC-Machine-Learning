📊 1. Descriptive Statistics & Summary Measures
Measures of Central Tendency, Dispersion & Shape
Central Tendency & Dispersion Master Table
Measure Type Mathematical Formula Outlier Sensitivity When to Use in Real-World
Mean (μ or x̄) Central Tendency x̄ = (Σ x_i) / n High Symmetric, bell-shaped normal distributions without extreme anomalies.
Median (Q2) Central Tendency Middle value of sorted data Robust Skewed data (e.g., Salaries, House prices, Net worth).
Mode Central Tendency Most frequent observation Robust Categorical/Nominal data (e.g., most purchased shoe size).
Variance (σ² / s²) Dispersion s² = Σ(x_i - x̄)² / (n - 1) Very High Measures squared spread; note Bessel's correction n - 1 for samples.
Standard Deviation (s) Dispersion s = √s² High Same unit as original data; essential for Z-scores and Normal distributions.
Interquartile Range (IQR) Dispersion IQR = Q3 - Q1 Robust Middle 50% spread; foundation for Tukey box plots and outlier clipping.
Skewness Distribution Shape E[((X - μ) / σ)³] Moment 3 Right-skewed: Mean > Median > Mode. Left-skewed: Mean < Median < Mode.
Kurtosis Distribution Shape E[((X - μ) / σ)⁴] - 3 Moment 4 Leptokurtic (>0): Heavy tails / extreme risks; Platykurtic (<0): Thin tails.
💡 Worked Example: Manual IQR Outlier Boundaries
Given dataset: [10, 12, 14, 15, 18, 20, 22, 25, 28, 90] (n = 10)
• Q1 (25th percentile) = 13.5  |  Q3 (75th percentile) = 23.5
• IQR = 23.5 - 13.5 = 10.0
• Lower Fence = Q1 - 1.5 * IQR = 13.5 - 15.0 = -1.5
• Upper Fence = Q3 + 1.5 * IQR = 23.5 + 15.0 = 38.5
• Conclusion: Value 90 lies outside [ -1.5, 38.5 ] and is flagged as an Outlier!

💡 Worked Example: Bayes' Theorem Disease Detection
Formula: P(Disease | Positive) = [ P(Positive | Disease) * P(Disease) ] / P(Positive)
• Disease Prevalence P(D) = 0.01 (1%) → P(No D) = 0.99 (99%)
• Sensitivity P(+ | D) = 0.95 (95%)
• False Positive Rate P(+ | No D) = 0.05 (5%)
• Total Probability of Positive P(+) = (0.95 * 0.01) + (0.05 * 0.99) = 0.0095 + 0.0495 = 0.0590
• Posterior Probability = 0.0095 / 0.0590 ≈ 0.1610 (16.1%)!
(Intuition: Even with a 95% accurate test, a rare disease yields mostly false alarms due to the 99% healthy base population!)

💡 The 3-Step P-Value Decision Rule
1. Set Significance Level: Standard α = 0.05 (5% risk of Type I Error).
2. Compare P-Value to α:
• If p < 0.05 → Reject H₀ (Statistically Significant difference exists).
• If p ≥ 0.05 → Fail to Reject H₀ (Insufficient evidence of effect).
3. Confidence Interval Rule: If the baseline value μ₀ falls outside the 95% Confidence Interval, reject H₀!
📋 4. Sampling Techniques & Data Feature Hierarchy
Probability vs Non-Probability Sampling & Encodings
Sampling Methods Comparison
Method Mechanism Key Advantage Main Limitation / Risk
Simple Random Every member has equal probability via random numbers (lottery). Completely unbiased representation. May under-represent small key minority subgroups.
Stratified Sampling Divide population into homogeneous strata (e.g. Gender, Age), sample from each. Guarantees proportional representation of all subgroups. Requires advance demographic knowledge of strata sizes.
Systematic Sampling Pick every k-th individual after a random start (k = N / n). Extremely simple and easy to implement. Hidden periodicity in data will severely bias results.
Cluster Sampling Divide population into heterogeneous clusters (e.g. cities), pick whole clusters. Cost-effective and logistically practical. Higher sampling error if clusters differ systematically.
Convenience Sampling Non-probability: Collect data from whoever is readily available. Fast and zero cost. High selection bias; cannot generalize findings statistically.
🤖 5. Machine Learning Algorithms Master Reference
Mathematical Objectives, Assumptions, Pros/Cons & Hyperparameters
Algorithm Task Core Mathematical Principle Key Assumptions Primary Hyperparameters Pros & Cons
Linear Regression Regression Ordinary Least Squares: min Σ(y_i - ŷ_i)² Linearity, Homoscedasticity, Normality of residuals, No multicollinearity. fit_intercept, Regularization: L1 (Lasso), L2 (Ridge) Pros: Highly interpretable, fast. Cons: Struggles with non-linear relationships.
Logistic Regression Classification Sigmoid σ(z) = 1 / (1 + e^-z) minimizing Log-Loss Linear relationship between log-odds and predictors. C (Inverse regularization), penalty (l1, l2), solver Pros: Outputs calibrated probabilities. Cons: Linear decision boundary only.
K-Nearest Neighbors (KNN) Classification / Regression Instance-based distance vote: Euclidean √Σ(x_i - y_i)² Nearby instances share similar labels. Distance metrics are meaningful. n_neighbors (k), metric (euclidean, manhattan), weights Pros: No training phase, non-linear. Cons: Slow inference O(n*d), sensitive to feature scale!
Decision Tree Classification / Regression Recursive greedy partitioning via Gini Impurity or Entropy/Information Gain Non-parametric. No distributional assumptions. max_depth, min_samples_split, min_samples_leaf, criterion Pros: Interpretable rules, no feature scaling needed. Cons: Extremely prone to overfitting!
Random Forest Classification / Regression Ensemble bagging: B bootstrap trees + random feature subsets Ensemble averaging reduces variance without increasing bias. n_estimators, max_depth, max_features, bootstrap Pros: High accuracy, handles non-linearity, out-of-bag error. Cons: Black-box model, slower.
Support Vector Machine (SVM) Classification / Regression Max-margin hyperplane; Kernel trick K(x, z) for non-linear mapping Data can be separated by a margin in transformed space. C (Margin penalty), kernel (linear, rbf, poly), gamma Pros: Effective in high-dimensional spaces. Cons: Computationally expensive on large N.
Naive Bayes Classification Bayes Theorem + strong conditional independence assumption All features are conditionally independent given class label. var_smoothing (GaussianNB), alpha (MultinomialNB Laplace) Pros: Ultra-fast training, great for NLP text/spam. Cons: Independence assumption rarely holds.
K-Means Clustering Unsupervised Clustering Minimizes Within-Cluster Sum of Squares (Inertia: Σ||x_i - μ_k||²) Spherical, equal-variance clusters; sensitive to initialization. n_clusters (k), init='k-means++', n_init Pros: Fast O(T*k*n). Cons: Must pick k in advance (Elbow Method), outlier sensitive.
Principal Component Analysis (PCA) Dimensionality Reduction Orthogonal projection maximizing variance via Eigenvalues of Covariance Matrix Linear relationships among variables. Large variance = high information. n_components Pros: Removes multicollinearity, compresses data. Cons: Components lose original interpretability.
🎯 6. Evaluation Metrics & Confusion Matrix Cheat Sheet
Classification & Regression Performance Benchmarks
2x2 Confusion Matrix Foundation
Confusion Matrix Predicted Positive (1) Predicted Negative (0) Row Totals
Actual Positive (1) True Positive (TP) False Negative (FN) (Type II Error) All Actual Positives (P = TP + FN)
Actual Negative (0) False Positive (FP) (Type I Error) True Negative (TN) All Actual Negatives (N = FP + TN)
Column Totals All Predicted Positives (TP + FP) All Predicted Negatives (FN + TN) Total Samples (N_total)
Metric Formulas & Optimization Scenarios
Metric Formula When to Prioritize Exam Trap to Remember
Accuracy (TP + TN) / (TP + TN + FP + FN) Balanced datasets where all classes are equally important. Useless on imbalanced data! 99% accuracy on 99:1 disease imbalance is trivial.
Precision TP / (TP + FP) When False Positives (FP) are costly (e.g. Email spam filter, YouTube copyright flags). A high threshold gives high precision but may miss many true positives.
Recall (Sensitivity) TP / (TP + FN) When False Negatives (FN) are fatal (e.g. Cancer detection, Fraud detection, Airport security). Predicting everything as Positive gives 100% Recall, but destroys Precision!
Specificity TN / (TN + FP) True Negative Rate: Proportion of actual negatives correctly identified. False Positive Rate (FPR) = 1 - Specificity.
F1-Score 2 * (Precision * Recall) / (Precision + Recall) Harmonic mean when you need a balanced trade-off between Precision and Recall. Penalizes extreme imbalances much more harshly than arithmetic mean.
ROC-AUC Area Under TPR vs FPR curve across all thresholds Threshold-independent evaluation of classification separation power. AUC = 0.5 means pure random coin toss; AUC = 1.0 means perfect separation.
Regression Metrics Master Summary
Metric Formula Units Key Property
MAE (Mean Absolute Error) (1/n) * Σ |y_i - ŷ_i| Same as target y Linear penalty; robust to extreme outliers.
MSE (Mean Squared Error) (1/n) * Σ (y_i - ŷ_i)² Squared units (y²) Penalizes large errors heavily; foundation of OLS calculus.
RMSE (Root Mean Squared Error) √MSE Same as target y Standard metric; directly comparable to target variable magnitude.
R² (Coeff of Determination) 1 - (SS_res / SS_tot) Unitless (≤ 1) % of variance explained; always increases when adding new features!
Adjusted R² 1 - [(1 - R²)(n - 1) / (n - p - 1)] Unitless (≤ 1) Penalizes useless predictor features p; only increases if feature truly adds value!
⚖️ 7. Bias-Variance Tradeoff & Diagnostics
Identifying Underfitting vs Overfitting & Prescribing Exact Remedies
Diagnostic Dimension High Bias (Underfitting) High Variance (Overfitting)
Model Complexity Too simple (e.g., straight line on quadratic data) Too complex (e.g., degree-20 polynomial, unpruned tree)
Training Error High Very Low (Near zero)
Validation / Test Error High High (Large gap with training)
What the Model Learned Failed to capture underlying patterns/signal Memorized training noise and random fluctuations
Actionable Remedies • Increase model complexity (higher degree, deeper tree)
• Engineer and add new polynomial/interaction features
• Decrease regularization strength (decrease λ / increase C) 		• Gather more training data
• Apply Regularization: L1 Lasso (feature selection) or L2 Ridge (weight decay)
• Prune decision trees (limit max_depth, increase min_samples_split)
• Use Ensemble Dropout / Bagging (Random Forests)
💡 Regularization Math: L1 (Lasso) vs L2 (Ridge)
• Ridge Regression (L2): Loss = MSE + λ * Σ (w_j)²
Shrinks coefficients toward zero asymptotically, but never sets them exactly to zero. Great for handling multicollinear features.
• Lasso Regression (L1): Loss = MSE + λ * Σ |w_j|
Forces coefficients of useless features to become exactly zero, performing automated sparse feature selection!
⚙️ 8. The 12-Step Feature Engineering Playbook
Synthesized from CDAC Hands-on Labs (Day 5 & 6)
Step # Technique Why It Matters Scikit-Learn / Pandas Implementation
1 Zero-Variance Removal Features with constant values carry zero information. VarianceThreshold(threshold=0.0)
2 Quasi-Constant Removal Features where >99% of entries are identical add noise. VarianceThreshold(threshold=0.01)
3 Multicollinearity Filtering Redundant features inflate variance in linear coefficients. df.corr().abs() > 0.85 drop redundant col
4 Missing Value Imputation Algorithms crash on NaN; preserve record integrity. SimpleImputer(strategy='median')
5 Outlier Treatment Extreme values distort gradient descent and mean. IQR clipping: np.clip(s, lower_fence, upper_fence)
6 One-Hot Encoding Convert nominal categories to binary vectors. pd.get_dummies(df, drop_first=True)
7 High-Cardinality Handling Prevents dimensionality explosion for postcodes/IDs. Frequency encoding: df['zip'].map(df['zip'].value_counts())
8 Power Transformations Normalizes heavily skewed continuous feature tails. np.log1p(x) or PowerTransformer(method='yeo-johnson')
9 Scaling & Normalization Equalizes gradient step sizes and distance metrics. StandardScaler() (Z-score) or MinMaxScaler() [0, 1]
10 Temporal Decomposition Extracts cyclic signals from raw timestamps. df['date'].dt.year, df['date'].dt.dayofweek
11 Binning & Discretization Turns noisy continuous values into robust ranges. pd.cut(df['age'], bins=[0, 18, 35, 60, 100])
12 Automated Feature Selection Keeps only top K most predictive features. SelectKBest(score_func=f_classif, k=10)
⚠️ 9. High-Yield Exam Pitfalls & Examiner Traps
Top 5 Conceptual Traps Tested in CDAC Multiple Choice & Viva Exams
🚨 Trap 1: The Accuracy Paradox on Imbalanced Datasets
The Trap: A candidate builds a model for a credit card fraud dataset with 990 valid transactions and 10 fraud transactions (99:1 ratio). The model outputs 99% accuracy. Is it a great model?
The Reality: NO! A dumb model that predicts "Valid" for every single transaction will achieve 99% accuracy while having a Recall of 0% (detecting zero frauds). Always evaluate with Precision, Recall, F1-Score, or PR-AUC on imbalanced datasets!
🚨 Trap 2: Data Leakage in Feature Scaling & Imputation
The Trap: Calling scaler.fit_transform(X) on the entire dataset BEFORE doing train_test_split(X, y).
The Reality: This leaks test set mean and variance into the training process! Always perform train_test_split first. Then call scaler.fit_transform(X_train), and only scaler.transform(X_test) on the test data!
🚨 Trap 3: The Dummy Variable Trap (Multicollinearity)
The Trap: Converting a categorical column with 4 distinct categories into 4 one-hot columns without dropping one.
The Reality: The 4th column is an exact linear combination of the first three (col_4 = 1 - col_1 - col_2 - col_3). This causes perfect multicollinearity, making the matrix (X^T * X) non-invertible for Linear and Logistic Regression. Always use drop_first=True!
🚨 Trap 4: Correlation Does NOT Imply Causation & r = 0 Trap
The Trap: If Pearson correlation r = 0, does it mean the two variables are completely independent?
The Reality: NO! Pearson's r only measures linear relationships. For a non-linear relationship like y = x² on a symmetric domain [-5, 5], the Pearson correlation is exactly 0, yet y is perfectly determined by x!
🚨 Trap 5: Misinterpreting P-Values as Probability of H₀ Being True
The Trap: "A p-value of 0.03 means there is a 3% chance that the null hypothesis is true."
The Reality: FALSE! A p-value is the probability of observing data at least as extreme as our sample, assuming that H₀ is already true: P(Data | H₀), NOT P(H₀ | Data).
